# AternosDektop

**A Minecraft launcher with Aternos web integration, designed to bring server management and Minecraft launching together in one desktop application.**

Aternos Desktop is an independent desktop application that combines an integrated Aternos web interface with a built-in Minecraft launcher. Its goal is to provide a convenient and lightweight way to access Aternos, manage Minecraft installations, and launch the game without having to switch between multiple applications.

## Features

- **Integrated Aternos Web:** Access the Aternos website directly from the application.
- **Built-in Minecraft Launcher:** Install and launch Minecraft directly from Aternos Desktop.
- **Offline Profiles:** Create and use local Minecraft profiles for offline-mode servers.
- **Version Management:** Browse, install, and manage different Minecraft versions.
- **RAM Configuration:** Choose how much memory Minecraft can use.
- **Independent Profiles:** Keep different Minecraft installations and their files separated.
- **Simple Interface:** A straightforward desktop experience focused on convenience and usability.

## Project Status

Aternos Desktop is currently under development. New features, improvements, and bug fixes are planned for future releases.
